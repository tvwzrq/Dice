# 骰子对决 · 配置更新

这是游戏的公开配置仓库，客户端从这里下载 Excel 数据。

- `latest.json`：当前数据版本、最低客户端版本、表结构版本、文件大小和 SHA256。
- `data/<SHA256>.xlsx`：按内容命名的配置快照；发布后不要修改同名文件。

客户端 0.2.0 起，在进入或返回大厅时自动检查清单。首次下载后缓存到本机，相同配置不重复下载。下载、摘要校验、Excel 解析成功后才开放创建和加入房间；对局中不切换数据。房主与加入者的配置摘要必须一致。更新失败时大厅显示原因，可以点击“重试更新”，不会静默改用旧配置开局。

## 发布数值改动

1. 修改 Unity 工程的 `Assets/StreamingAssets/DiceDuel.xlsx`。
2. 在当前 Unity 编辑器执行 `Dice Duel > 配置 > 导出更新数据`。输出在工程根目录的 `DataRelease`。内容不变时版本号不增加；内容变化时版本号递增。
3. 将新的 `data/<SHA256>.xlsx` 和 `latest.json` 一起提交到本仓库的 `main`。若分次上传，先上传数据文件，最后更新清单。发布前确认清单版本高于仓库当前版本。
4. 玩家返回大厅或重启游戏，自动取得新配置；无需重建 exe。

日常可以直接让开发助手完成校验、导出和发布。不要只修改 Excel 而遗漏清单，也不要删除仍被清单引用的数据文件。

## 更新范围

可以调整当前表结构支持的血量、攻击、骰子点数、卡牌名称、牌库配比、已有图标索引、商店价格、野怪及陷阱数值、刷新权重、已有魔法参数、回合时限。

当前客户端固定为11种卡牌、最多5张手牌、36格图集及已有魔法行为。新增 C# 行为、图集、界面结构或改变通信协议需要更新客户端。普通配置下载不包含代码和美术资源热更新。

## 清单约定

字段区分大小写。`Schema` 当前为1；`Version` 为正整数；`MinClient` 为最低客户端版本；`Bytes` 为 Excel 字节数；`Sha256` 为64位大写十六进制摘要。客户端下载地址为 `data/<Sha256>.xlsx`，不接受清单指定任意本地路径。

GitHub连接不可用时无法确认最新版本，大厅会暂停开局并允许重试。公开仓库不需要向玩家发放 GitHub 令牌。
